# ml-product-classifier
### Proceso de automatización para reducción de tiempos con clases en python y modelos de ML
El proceso que se automatizó se hacía de manera manual y llevaba más de 1 hora y media realizarlo, por lo que tanto los procesos manuales de actualización de archivos, actualización de sheets, etc se hace desde estas clases y se manda a llamar en un archivo main que no se pondrá aquí por una mayor seguridad de las variables de la empresa.

### Referente al modelo de ML entrenado
Adicional a automatizar proceso el mayor ahorro de tiempo se lo llevo el entrenar un modelo con ramdom forest para clasificar automáticamente las decisiones de clasificación de diversos artículos, que anteriormente se hacía entre 4 personas y cada una aproximadamente solía clasificar más de 1000 artículos a ojo, tomando más de 2 horas solo este proceso por lo regular. Por lo que este modelo es el mayor logro en esta sección pues el código main al aplicar el modelo tarda hasta 1 minuto en terminar.

#### Descripción de archivos
- listados.py : Es el archivo ultimo del proceso que se automatizo para la mezcla de listados, antes se tenia con formulas largas y pesadas en sheets y con este proceso se hace mucho más eficiente y replicable, sin estar gastando demasiada memoria
